### ACT-ONE

Модуль **ACT-ONE** - это всего лишь символичный заголовок практического этапа по освоению ООП в Python и написанию автотестов с использованием `pytest`.

#### Структура модуля и назначение файлов

* **`src/act_one/`** - исходный код:
  * `__init__.py` - делает директорию Python-пакетом (Package), позволяя выполнять относительные импорты в тестах без ошибок `ModuleNotFoundError`.
  * `character_creator.py` - реализация класса и логики создания персонажей.

* **`tests/`** - тесты:
  * `test_character_creator.py` - набор `pytest`-тестов для проверки валидации входных данных, инициализации и методов класса `CharacterCreator`.

#### Окружение и конфигурация проекта

* **`README.md`** - документация проекта (Вы здесь :))
* **`.python-version`** - фиксирует используемую версию Python (3.14)
* **`pyproject.toml`** - настройки зависимости, линтера `ruff` и фреймворка `pytest`.
* **`python.ini`** - конфигурация параметров запуска тестов (пути к тестам, флаги, маркеры).
* **`uv.lock`** - lock-файл менеджера пакетов `uv`, гарантирующий воспроизводимость окружения и точные версии зависимостей.
